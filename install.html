Android · Chrome

1
Open this page in Chrome

Use Chrome directly, not an in-app browser opened inside another application.

2
Install the app

Tap the installation button when it becomes available, then confirm the browser prompt.

3
Use the browser menu if needed

Open Chrome menu ⋮ and look for Install app or Add to Home screen. The option appears only when Chrome allows installation.

iPhone · Safari

1
Open this page in Safari

Use Safari, then tap the Share button.

2
Add to Home Screen

Choose Add to Home Screen. Turn on Open as Web App, then tap Add.

Computer · Supported browsers

Look for the install icon in the browser address bar or open the browser menu and choose Install app, when offered.

Offline use and cloud sync: Some supported records can be saved on this device when offline, but not every screen or feature works without internet. Cloud synchronisation is not automatic. When connected, sign in, select the correct business workspace and use Sync local records. Check the sync status before relying on those records on another device. Clearing browser or app data can remove records that have not synced.
